# T-17. Календарь, отмена, перенос, разовые занятия

**Цель.** Админ видит расписание школы на неделю или день, открывает занятие, отменяет его, переносит или добавляет
занятие вне расписания.

**Требования:** FR-15, FR-16; экран W-3. Решение Q-5: отменяет и переносит только владелец и админ.

## Прочитать перед началом

- Прототип: `THome` в `design/sample/screens-teacher.jsx` — карточки занятий с цветной колонкой времени.
- Модуль `lessons` и `packages/shared/src/domain` (T-16), `apps/web/src/lib/dates.ts`.

## Решения (уже приняты)

1. **Дата и время в запросах — местные для школы:** `{ date: 'YYYY-MM-DD', time: 'HH:mm' }`. Сервер переводит в UTC
   функцией `zonedDateTimeToUtc`. Так браузер в другом часовом поясе не сдвинет занятие.
2. **Отменить и перенести можно только занятие со статусом `planned`;** иначе 409 `LESSON_NOT_PLANNED`.
   Отменённое занятие можно вернуть (`cancelled` → `planned`): оно продолжает занимать слот группы, поэтому
   разовое на то же время создать нельзя (добавлено при приёмке). Вернуть не `cancelled` — 409 `LESSON_NOT_CANCELLED`.
3. **Перенос меняет `startsAt`, а `originalStartsAt` запоминает самое первое время** (при повторном переносе
   не перезаписывается). Генератор из T-16 уже не заполняет освободившийся слот.
4. **Накладки преподавателя — предупреждение в ответе**, не отказ.
5. **Занято время у группы** (уникальный индекс `groupId + startsAt`) — 409 `LESSON_SLOT_TAKEN`.
6. **Новый компонент `Drawer`** в `packages/ui` (правая панель 360 px на нативном `<dialog>`, как `Dialog`).
   Он понадобится и карточке ученика.
7. **Скорость (FR-16: неделя на 100 занятий быстрее 1 с).** Один запрос к базе на список, без запросов в цикле.
   База разработки — облачная и далёкая, поэтому автотест проверяет мягкий порог 3 с (ловит только грубые ошибки),
   а фактическое время на 100 занятиях исполнитель замеряет и пишет в отчёте.

## API (дополнение модуля `lessons`)

Все эндпоинты — `@SchoolRoles('owner', 'admin')`.

| Эндпоинт | Поведение |
|---|---|
| `GET /lessons?from&to&teacherId&courseId&groupId` | Добавить фильтры по преподавателю и курсу |
| `GET /lessons/:id` | `LessonDto` + `group { capacity, enrolledCount }` |
| `POST /lessons` | Разовое: `{ groupId, date, time, durationMin (15–480), teacherMembershipId?, meetingUrl? }`. Преподаватель по умолчанию — из группы. Группа и курс не в архиве |
| `POST /lessons/:id/cancel` | `{ reason }` 1–300 символов → `cancelled` |
| `POST /lessons/:id/restore` | Без тела: `cancelled` → `planned`, причина очищается. Группа и курс не в архиве |
| `POST /lessons/:id/reschedule` | `{ date, time, durationMin? }` |
| `PATCH /lessons/:id` | `{ meetingUrl?, teacherMembershipId? }` — ссылка и замена преподавателя на одно занятие |

Ответы `POST /lessons`, `reschedule` и `PATCH` с новым преподавателем: `{ lesson, conflicts }` (формат накладок —
как в T-16). Преподаватель проверяется так же, как в группах (T-15, решение 6). Отмена, перенос, создание и замена
преподавателя — в `AuditLog` (entity `Lesson`, `before`/`after`).

Индекс `(school_id, starts_at)` уже есть; убедись по плану запроса или по коду, что список за неделю — один запрос
с `include`, а не N запросов.

## Веб

Страница `apps/web/src/pages/schedule/SchedulePage.tsx` вместо заглушки.

- **Шапка:** заголовок с периодом («12–18 мая»), стрелки «назад / вперёд», «Сегодня», переключатель `Segmented`
  «Неделя / День», кнопка «Разовое занятие».
- **Фильтры:** преподаватель, курс, группа (`Select`, пустое значение — «Все»); выбор сохраняется в адресе
  страницы (`?view=week&date=…&teacher=…`), чтобы ссылка открывала тот же вид.
- **Неделя:** семь колонок Пн–Вс с датой (`DateBlock`), в колонке — карточки занятий по времени: цветная полоса
  пастели курса, время «15:00–16:00», группа, преподаватель. Отменённое — приглушённое, с пометкой «Отменено».
  Перенесённое — пометка «Перенесено с 14 мая». Сегодняшняя колонка выделена. На узком экране колонки
  прокручиваются по горизонтали.
- **День:** список строк `LessonRow` (сетка `64px 1fr auto`) за один день.
- **Пустые состояния:** нет занятий за период; нет ни одной группы с расписанием (со ссылкой на «Курсы»).
- **Карточка занятия** — `Drawer` по клику: курс и группа (ссылка на страницу группы), дата и время, преподаватель,
  ссылка на звонок («Скопировать», «Изменить»), статус. Действия для `planned`: «Перенести» (дата, время,
  длительность), «Отменить» (причина обязательна), «Заменить преподавателя». Блоки «Посещения» и «Домашнее задание» —
  `EmptyState` с пометками `TODO(T-22)` и `TODO(T-34)`.
- **Диалог разового занятия:** группа, дата, время, длительность, преподаватель (по умолчанию из группы).
- После действия с накладками — предупреждение со списком, как в T-16.
- Всё время — в поясе школы (`apps/web/src/lib/dates.ts`). Неделя начинается с понедельника.

## Тесты

`apps/api/test/lessons.e2e-spec.ts`:

- `describeSchoolIsolation` для всех эндпоинтов, пути с `:id` — с занятием школы A; права ролей
  (преподаватель и родитель — 403);
- фильтры по преподавателю, курсу, группе; диапазон больше 62 дней — 400;
- разовое занятие: создаётся с `isOneOff: true`, местное время переведено верно для `Asia/Dushanbe`; занятый слот — 409;
  архивная группа — 409;
- отмена: статус и причина сохранены; повторная отмена — 409; пустая причина — 400;
- перенос: `originalStartsAt` равен первому времени и не меняется при втором переносе; после `syncGroup`
  исходный слот не заполнен, перенесённое занятие на месте;
- отменённое занятие после `syncGroup` остаётся отменённым, дубль не появляется;
- накладка при переносе возвращается в `conflicts`, занятие перенесено;
- замена преподавателя на одно занятие не меняет группу и другие занятия;
- 100 занятий за неделю (создай `createMany`) отдаются одним вызовом быстрее мягкого порога.
