# T-13. Настройки школы

**Цель.** Владелец редактирует профиль школы, правила списания и напоминаний, получает ссылку и QR-код для родителей.
Заодно в панели появляется общий источник данных о текущей школе (часовой пояс, валюта) — им пользуются все
следующие задачи.

**Требования:** FR-7, FR-8, FR-9; экран W-13.

## Решения (уже приняты)

1. **Логотип не делаем.** Он требует хранилища файлов, которое появится в T-34. Поле `logoFileId` не трогаем.
2. **Журнал аудита на этом экране не делаем** — T-26.
3. **Блокировка валюты.** Оплат ещё нет, поэтому `SchoolsService.isCurrencyLocked(schoolId)` пока всегда возвращает
   `false` с пометкой `TODO(T-25)`. Но вся остальная цепочка делается сейчас: поле `currencyLocked` в ответе, отказ
   409 `CURRENCY_LOCKED` при попытке сменить валюту, заблокированный выбор в форме. Тест подменяет метод через `vi.spyOn`.
4. **QR-код рисует браузер**, а не сервер: библиотека `qrcode` (и `@types/qrcode`) в `apps/web`. API отдаёт только ссылку.
   (В ARCHITECTURE.md есть `GET /school/join-link` с PNG — он не нужен.)
5. **Ссылка для родителей:** `https://t.me/<BOT_USERNAME>?start=<код школы>`. Формат `?startapp=` — T-40.
6. **Доступ:** читать настройки — владелец и админ; менять — только владелец. Преподаватель и родитель получат свой
   урезанный вид школы в задачах Mini App.

## API

Модуль `apps/api/src/modules/schools`. Контракты — `packages/shared/src/contracts/school.ts`.

**`GET /school`** — `@SchoolRoles('owner', 'admin')`. Ответ `SchoolDto`:
`id, name, code, currency, timezone, defaultLocale, address, phone, description, chargeAbsent, chargeExcused,
reminderHoursBefore, debtRemindersEnabled, currencyLocked, joinUrl`.

**`PATCH /school`** — `@SchoolRoles('owner')`. Все поля необязательны, хотя бы одно должно быть:

| Поле | Правило |
|---|---|
| `name` | 2–120 символов |
| `address` | до 200; пустая строка → `null` |
| `phone` | до 32, `^[+\d][\d\s()-]{4,30}$`; пустая строка → `null` |
| `description` | до 1000; пустая строка → `null` |
| `timezone` | `timeZoneSchema` из `contracts/platform.ts` |
| `currency` | `TJS` / `RUB`; при `currencyLocked` и другом значении — 409 `CURRENCY_LOCKED` |
| `defaultLocale` | `ru` / `tg` |
| `chargeAbsent`, `chargeExcused`, `debtRemindersEnabled` | boolean |
| `reminderHoursBefore` | целое 1–48 |

Каждое изменение — запись в `AuditLog` (entity `School`, action `update`, в `before`/`after` только изменённые поля).
Смена правила списания не трогает существующие данные (FR-8: действует на новые отметки).

## Веб

- **`apps/web/src/app/school.ts`** — хук `useSchool()`: запрос `GET /school` с ключом `['school']`. Возвращает
  `SchoolDto`. Его будут использовать расписание (часовой пояс) и деньги (валюта). Мутация настроек обновляет этот кэш.
- **Страница `apps/web/src/pages/settings/SettingsPage.tsx`** вместо заглушки в `router.tsx`. Карточки (`Card`):
  1. **Профиль** — название, адрес, телефон, описание для родителей, часовой пояс, валюта, язык по умолчанию.
     Список часовых поясов вынести из `SchoolDialog.tsx` в общий файл и использовать в обоих местах.
     Заблокированная валюта: поле выключено, подпись «Валюту нельзя сменить после первой оплаты».
  2. **Списание при отсутствии** — два переключателя: «Списывать занятие при пропуске», «…при уважительной причине».
     Подпись: изменение действует только на новые отметки.
  3. **Напоминания** — за сколько часов напоминать о занятии; переключатель напоминаний о долге.
  4. **Ссылка для родителей** — ссылка с кнопкой «Скопировать», QR-код и кнопка «Скачать PNG» (512×512, имя файла
     `darsi-<код>.png`).
- Каждая карточка 1–3 сохраняется своей кнопкой; кнопка активна только при изменениях; после сохранения — короткое
  подтверждение на месте.
- Переключатель: добавить компонент `Switch` в `packages/ui` (доступный `role="switch"`, стиль — пилюля ink/hairline)
  и показать его на странице `/ui`.

## Тесты

`apps/api/test/school.e2e-spec.ts`:

- `describeSchoolIsolation('school', …, [GET /school, PATCH /school])`;
- владелец читает и меняет; админ читает, на PATCH — 403 `FORBIDDEN_ROLE`; преподаватель и родитель — 403 на оба;
- пустые строки превращаются в `null`; неверный часовой пояс, телефон, `reminderHoursBefore: 0` — 400;
- пустое тело — 400;
- смена валюты проходит; при подменённом `isCurrencyLocked → true` — 409, а запрос с той же валютой проходит;
- запись аудита содержит только изменённые поля;
- `joinUrl` равен `https://t.me/darsi_test_bot?start=<код>`.

## Готово, когда

- [ ] Владелец меняет настройки в браузере, после перезагрузки страницы значения сохранены.
- [ ] Админ не видит раздел «Настройки» (меню) и получает отказ на изменение (API).
- [ ] QR-код скачивается PNG-файлом и ведёт на ссылку школы (проверь любым распознавателем или сравни текст
      закодированной ссылки в коде страницы — и напиши в отчёте, каким способом проверено).
- [ ] `useSchool()` используется на странице настроек и готов для других страниц.
- [ ] Общий список из `docs/tasks/README.md`.

## Не входит

Логотип; журнал аудита; вид школы для преподавателя и родителя; настройки уведомлений родителя (T-39).
